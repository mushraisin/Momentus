# 🧠 AI Community Bot

Discord-бот нового покоління: **Community Manager + Moderator + Reputation System + Analytics** в одному.
Керування **виключно через графічний інтерфейс Discord** — кнопки, меню, модальні вікна, панелі, контекстні меню. **Жодних slash / prefix / текстових команд.**

> ⚙️ Аналітика працює **без ШІ за замовчуванням** — детермінований правило-рушій (лексикони + regex + поведінкові сигнали). LLM (Ollama/Anthropic) — опційний апгрейд. Деталі — у розділі «[Аналітичне ядро](#аналітичне-ядро-за-замовчуванням--без-ші)».

## Архітектура

```
src/
├─ index.js                 Точка входу, gateway-клієнт
├─ config/                  Константи, схема конфігурації, правила ролей/ачивок
├─ core/                    Логер, кеш, черги задач, шина подій
├─ database/                SQLite (better-sqlite3), схема, репозиторії
├─ services/                Бізнес-логіка (модульні сервіси)
│  ├─ aiService.js          Anthropic SDK + structured JSON output (+ евристичний резерв)
│  ├─ reputationService.js  Розрахунок 11 категорій та AI Score
│  ├─ analysisPipeline.js   Пакетний аналіз повідомлень → репутація → ролі → ачивки
│  ├─ moderationService.js  Виконання дій + історія + AI-поради
│  ├─ profileService.js     Збірка готового профілю
│  └─ …                     ролі, досягнення, доступ, трекінг, бекапи, планувальник
├─ ui/                      Тема, компоненти, embed-и, панелі, модалки
└─ interactions/            Роутер усіх взаємодій + gateway-обробники
```

**Принципи:** модульні сервіси, кешування, черги з ретраями, подієва шина, SQLite з WAL, автоматичні бекапи (`VACUUM INTO`), логування. Розширюється без перебудови.

## Аналітичне ядро (за замовчуванням — БЕЗ ШІ)

Основний режим не потребує жодної LLM, ключів чи інтернету — це **детермінований правило-рушій** (`src/services/analysis/`):

- **Нормалізація/деобфускація** (`normalize.js`) — розкриває спроби обійти фільтр: розтягнуті літери (`суууука`→`сука`), латинські гомогліфи (`cyka`→`сука`), леетспік, пробіли між буквами, zero-width.
- **Лексикони uk/ru/en** (`lexicons.js`) — зважені стеми по категоріях: лайка, образи, погрози, пасивна агресія, провокації, реклама, подяка, ввічливість, допомога, конектори, позитив.
- **Детектори + поведінкові сигнали** (`ruleEngine.js`) — CAPS, повтори, згадки, посилання, **частота повідомлень і дублікати** (детекція флуду/спаму без аналізу тексту).
- **Інсайти на формулах** (`insightsEngine.js`) — рекомендації, прогноз (модератор/адмін/ризики), поради модератору — усе детерміновано.

На виході — ті самі **21 ознака (0..100) + flag + summary** і ті самі інсайти, що були б від LLM, але миттєво й безкоштовно.

**Опційно** можна підключити LLM для тоншого аналізу (`AI_PROVIDER`): `ollama` (локальна модель) або `anthropic` (хмара, `output_config.format`). Якщо LLM недоступна або впала — система прозоро повертається до правило-рушія. Додати новий провайдер — один файл у `src/services/ai/` з методом `generate({ system, prompt, schema, maxTokens }) → { data, usage }`.

> Тобто «з коробки» бот повністю функціональний **без ШІ**. LLM — це апгрейд, а не залежність.

## Сховище (Turso / локальний файл)

Шар даних працює на **`@libsql/client`** (libSQL — сумісний із SQLite):

- **Turso (рекомендовано для хостингу):** задай `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` — дані живуть у хмарі й **переживають ефемерний безкоштовний хост** (Railway, Render, Fly тощо). Безкоштовний тариф щедрий.
- **Локальний файл (розробка):** якщо змінні Turso порожні — використовується `file:<DATABASE_PATH>`.

Як отримати Turso: зареєструйся на https://turso.tech → створи БД → `turso db show <name> --url` (URL) та `turso db tokens create <name>` (токен) → впиши у `.env`.

## Встановлення

```bash
cd discord-ai-community-bot
npm install
cp .env.example .env      # заповніть токен та ключ
npm run deploy            # зареєструвати контекстні меню (right-click → Apps)
npm start
```

### Змінні середовища (`.env`)

| Змінна | Опис |
|---|---|
| `DISCORD_TOKEN` | Токен бота |
| `DISCORD_CLIENT_ID` | Application ID |
| `DISCORD_GUILD_ID` | (dev) миттєва реєстрація меню для однієї гільдії |
| `ANTHROPIC_API_KEY` | Ключ Anthropic. Без нього — режим евристик |
| `AI_MODEL` | `claude-opus-5` за замовчуванням |
| `AI_EFFORT` | `low`…`max` |
| `AI_DISABLED` | `true` — повністю без AI |

> Потрібні привілейовані intents: **Server Members** та **Message Content** (увімкніть у Developer Portal).

### Кінотеатр і yt-dlp

У `bin/yt-dlp_linux` уже лежить готовий бінарник для Linux-хоста — просто залийте
його разом із проєктом. Бот знаходить його сам, нічого налаштовувати не треба,
і сам відновлює право на запуск, якщо панель хостингу його зняла.

Він потрібен, щоб діставати **пряме посилання на відео** з чужих сайтів: тільки
тоді фільм грає наш плеєр, а отже працює повна синхронізація — спільна пауза,
перемотка й підгонка часу для всіх у залі. Без нього кінотеатр теж працює, але
незнайомі сайти показуються рамкою, де спільна лише пауза.

| Змінна | Опис |
|---|---|
| `YTDLP_PATH` | Свій шлях до бінарника (за замовчуванням шукається `bin/yt-dlp_linux`, потім PATH) |
| `YTDLP_TIMEOUT_MS` | Скільки чекати на розбір посилання, типово 20000 |
| `PROXY_SECRET` | Ключ підпису для `/stream`. Порожньо — виводиться з токена бота |

Перевірити після запуску: у логах має зʼявитись рядок `yt-dlp <версія> — <шлях>`.
Оновити колись потім:

```bash
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp_linux -o bin/yt-dlp_linux
```

## Як користуватись (без команд)

1. **Опублікувати хаб:** right-click на будь-кому → `Панель адміністратора` → «Опублікувати хаб» у канал статистики.
2. **Користувачі** натискають кнопки хабу: Профіль, Статистика, AI-аналіз, Досягнення, Рейтинг.
3. **Модератори:** right-click на користувачі → `Модерувати` → кнопки дій → модалка з причиною (AI-порада додається автоматично).
4. **Адміни:** right-click → `Панель адміністратора` → меню розділів конфігурації, ваги, AI-керування.
5. **Власник** (`574231866396114944`) додатково бачить **Developer Panel**.
